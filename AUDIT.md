# Portfolio audit — 29 October 2026

## Initial state

The repository contained substantial EDA, machine-learning modules, notebooks, charts, a static dashboard, and a second 600-loan synthetic experiment. It lacked a single reproducible, defensible portfolio entry point. The README described practice work rather than a completed analytical case study.

## Findings and resolution

| Finding | Resolution |
|---|---|
| Supplied PD and derivatives entered exploratory features | New explicit allowlist excludes supplied PD, losses, risk-weighted assets, recoveries, and outcome durations |
| Target encodings constructed before downstream model folds | Canonical pipeline uses training-only one-hot encoding; no target encodings |
| Unclear training/holdout distinction | Fixed chronological cohort holdout from 2022-03-01; both models reported |
| Existing near-perfect model scores | Superseded by freshly computed holdout metrics and source hash |
| Classifier scores could be confused with annual PD | Lifetime outcome limitation displayed; annual stress uses supplied synthetic PD separately |
| Raw source attribution incomplete | Public artifact contains aggregates only; provenance limitation explicit |
| No focused tests | Tests cover allowlist, nonoverlapping cohorts, source validation, and bounded monotone stress |
| No concise deliverable | Standalone HTML and Markdown evidence reports generated by the pipeline |

## Explicitly retired evidence

The old `outputs/models` and `outputs/stress` files are historical, not regenerated canonical results. The separate `private_credit/python/03_ml_classifier.py` uses whole-sample scaling before CV and calibrated predictions on fitted data; its generator also makes coupon structure depend on distress status, making coupon-related predictors outcome-adjacent. The Monte Carlo experiment and workbook contain additional assumptions not validated here. Rather than relabel those artifacts as reliable, the portfolio excludes them entirely.
